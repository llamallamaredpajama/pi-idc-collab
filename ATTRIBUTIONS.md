# Attributions

This repository is a standalone package. When code is copied or adapted from `pi-harnesses`, attribution is required from the commit where the adapted file first lands.

## Attribution header convention

Every adapted source file must include a short attribution header near the top of the file. The header must name:

- Source repository: `pi-harnesses`
- Source path in `pi-harnesses`
- The fact that the local file is adapted for `pi-idc-collab`
- Any material adaptation notes needed to understand divergence from the source

Example header shape:

```ts
// Adapted from pi-harnesses/<source-path> for pi-idc-collab.
// Adaptation notes: <brief note of local changes>.
```

## License notice preservation

Original MIT license notices from adapted `pi-harnesses` files are preserved verbatim. Do not remove or weaken upstream copyright or license text when copying/adapting code.

Project-level guidance also lives in `CLAUDE.md` / `AGENTS.md` under the non-negotiable standalone-and-attribution rules.
