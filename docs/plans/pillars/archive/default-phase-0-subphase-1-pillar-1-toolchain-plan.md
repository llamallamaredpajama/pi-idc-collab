## Goal

Establish the Bun/TypeScript package scaffold and test-runner wiring so `bun install && bun test` runs green from a fresh clone: `package.json` (module type, `test` script), `tsconfig.json`, the Bun lockfile, a placeholder smoke test, and `.gitignore` coverage for `.claude/worktrees/`.

## Scope

- `package.json` with `"type": "module"`, `"private": true`, and a `test` script invoking `bun test`.
- `tsconfig.json` — strict TypeScript configuration suitable for Bun (no emit; Bun executes TS directly).
- `bun.lock` generated by `bun install`.
- `tests/smoke.test.ts` — one trivial passing test wiring the runner (see subphase plan D5).
- `.gitignore` extended with `.claude/worktrees/` (targeted pattern per subphase plan D3 — NOT blanket `.claude/`).

## Non-scope

- Any linter/formatter or extra devDependency beyond what `bun test` strictly requires (subphase plan D2).
- Any runtime dependency — Phase 0 has no runtime behavior.
- The spec §2 directory tree (pillar-2-layout), CI workflow, and attribution docs (pillar-3-ci-attribution).
- Version pinning beyond the lockfile — spec §1 pins no Bun/TS versions; the lockfile is the only pin.

## Work Packets

### toolchain-task-1 — Package manifest + lockfile

Author `package.json` (`"type": "module"`, `"private": true`, `scripts.test = "bun test"`) and generate `bun.lock` via `bun install`. Zero runtime dependencies; devDependencies only if strictly required for types (e.g. `@types/bun`).

**File surfaces:** package.json, bun.lock
**Test targets:** (covered by toolchain-task-3 smoke test)
**Acceptance criteria:** `bun install` exits 0 and produces `bun.lock`; `package.json` parses with `bun pm ls` exiting 0.

### toolchain-task-2 — TypeScript configuration

Author `tsconfig.json` with strict settings appropriate for Bun-executed TypeScript (e.g. `"strict": true`, bundler-style module resolution, no emit). Keep minimal — no path aliases, no project references.

**File surfaces:** tsconfig.json
**Test targets:** (covered by toolchain-task-3 smoke test — the TS test file exercises the config)
**Acceptance criteria:** `bun test` exits 0 with the TS smoke test compiled/executed under this config.

### toolchain-task-3 — Test-runner wiring + .gitignore coverage

Write `tests/smoke.test.ts` FIRST (a trivial assertion proving the runner executes TypeScript), confirm `bun test` goes green, then append `.claude/worktrees/` to `.gitignore` (append-only; preserve existing entries). Verify current Bun behavior on a zero-test-file suite: if `bun test` exits non-zero with no test files, the smoke test is mandatory (subphase plan D5).

**File surfaces:** tests/smoke.test.ts, .gitignore
**Test targets:** tests/smoke.test.ts
**Acceptance criteria:** `bun test` exits 0 reporting ≥1 pass; `git check-ignore -q .claude/worktrees/probe` exits 0.
